# web3-miniapp

Production-ready Telegram Mini App monorepo for Web3 Token Launch product.

Repository structure:

- apps/web: Next.js frontend (App Router)
- apps/api: NestJS backend
- packages/ui: Design system and Tailwind tokens
- packages/lib: Shared types, Zod schemas, API clients
- infra: Docker, docker-compose, k8s manifests

See docs/ for more detailed design and architecture notes.
